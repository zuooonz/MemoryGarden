# 《爷爷的一周》剧情与关卡一览

更新：2026-09-25｜供用户先审剧情，再试玩。人物、剧情由助手起草，均可修改。

## 人物与设定

- **爷爷**：姓李（街坊叫他“老李”），在小镇住了四十年，退休前是会计。早期认知变化：近事记不住、陌生路口容易走错；几十年前的地方和事记得牢。想自己出门、自己过日子——他始终是有主见、能干的人。
- **你**：他身边的人——家人、老伴、老街坊都行（中性写法，不做身份选择）。往事由爷爷自己讲（“我闺女”“我老伴”），老人和年轻人都能代入。
- **孙女**：上小学，常来陪爷爷。
- **小镇**：家、公园棋亭、菜市场、药店、快递驿站、社区中心、小学；老地标：老榕树、老电影院、老水井；可拜托的邻居：王阿姨、刘师傅、赵大爷、陈老板。

## 每天的固定结构

早上布置（每天 3 点精力放道具；邻居 2 点，其余 1 点）→ 白天看他按自己的习惯出门办事 → 当下帮忙（犹豫时等一等 → 轻轻提示 → 直接告诉；电话、陪同，看时机）→ 当天的小关卡（与当天核心任务相关）→ 他在往事发生的地方讲一段往事（没走到就晚上回家讲）→ 结算三颗星（都办成了／他自己办的／心情）。第 2、4、5、6 天还有邻居托他顺路带东西。

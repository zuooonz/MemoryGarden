# 项目基线

更新：2026-10-21（项目收尾、仓库公开）｜本页记录已确认的设计决定与不可突破的边界。

## 作品

- **名称**：《爷爷的一周》（用户选定）。副标题“买菜、下棋、接孙女，他想自己来”（09-27 用户定维持）。
- **形式**：单人浏览器游戏，电脑与手机都能玩；单个 HTML 文件，无外部素材。
- **参赛**：AIGCC 2026 小红花游戏赛道（适老关怀），入围 32 强；10-16 线上路演后未进入 8 强。10-21 收尾，仓库公开。
- **技术**：参考 claude-opus-5-5-demo 的方法（Three.js＋程序化几何／动作／音频＋esbuild 单文件打包），不复制其代码与内容。工程在 `Game/`。

## 核心原则（用户 10-05 确认，10-10 改为三层）

**① 价值目标**：让家属理解他，学会帮他自己把日子过下去。

**② 核心体验（不变）**：你是他身边的人；帮少、帮多都有代价，**后果带到第二天**（跨天后果保留，用户 10-10 再次确认）。这是作品最难被复制的部分。后果只落在他的信心、心情和家里放不放心上，不落在病情上。

**③ 手段（放开）**：雾（他心里不确定的地方）、俯视看着他、“进他眼里”看一眼、第一人称片段、对话……都可以用。判断标准只有一条：**玩家在里面看到、经历到的，会不会改变他接下来怎么帮？** 会，就是加强；不会（只体验一遍难、另起一套推理玩法、藏起他让你猜、另造一张与帮无关的地图），就是稀释。

（10-05 原文：“雾＝他心里的地图；帮少帮多都有代价（后果带到第二天）……另起一套能力、改掉‘你看着他、看时机帮’的视角、给雾之外再造一张‘他的地图’，都是在稀释。”10-10 用户定改为三层：目标和核心体验不变，表现手段不再限定视角。）

## 玩法（已确认）

爷爷有早期认知变化，仍想自己过日子。玩家每天：提前布置小镇支持（路标、便签、药盒、邻居……，花精力）→ 看他出门办事 → 当下帮忙（犹豫时按“等一等 → 轻轻提示 → 直接告诉”；电话、陪同，不花精力、看时机）→ 完成当天与核心任务相关的小关卡 → 他在往事发生的地方讲一段往事 → 结算三颗星（都办成了／他自己办的／心情）。共 7 天。规则与数值见 [游戏系统](./游戏系统.md)。详见 [剧情与关卡一览](./剧情与关卡一览.md)。

- 每天标题＝当天核心任务；小关卡为核心任务服务，并参考认知量表的一种题型（延迟回忆、连续减法、数字顺序、交替连线、画钟、三步指令、持续注意、照样复制）。
- 爷爷姓李，街坊叫他“老李”（用户 09-25 定）。
- “你”用中性写法：他身边的人（家人、老伴、老街坊都行），不做身份选择，也不配音。
- 反诈是重要主题（第 6 天完整章节）。

- 开场（09-27 现状）：约 30 秒实时画面——清晨天际线俯冲进小镇 → 他沿熟路走到不熟的路口，雾升起、他犹豫 → 刘师傅指路、路标立起、雾散 → 拉远看全镇，两句字（09-27 用户定维持现状），标题大字淡入；按画面节拍写的生成式配乐。第一次点「开始」时播放（浏览器要点一下才能出声），可跳过；玩过第 1 天后在主菜单“选择一天”那行的「开场动画」重看。
- 雾（用户 09-26 定）：雾＝他心里不再确定的地方，是玩法反馈，始终显示；不再提供菜单开关，设置里给“雾的浓淡：标准／淡”（只改显示）。

- 时间（用户 09-26）：小关卡、犹豫时刻、讲往事时游戏时钟停着（不给老人压力），做选择花掉的时间会明确显示；是否随难易程度设置调整，后面再定。
- 朗读提示（默认关）：只念“现在要你做什么、正在发生什么”，不念人物已说的话、结果、科普、手册、结算（见声音设计）。
- 星与成就（09-27 用户定）：第二颗星“他自己办的”＝至少三分之二；成就 5 个；一周总结页标题「一周总结」。
- 心情（09-28 用户定）：喜欢的事只按三成；小关卡只加不扣。
- 重玩（09-28 用户选 B）：每天保留最好的一次，通关后重玩不把记录改差。
- 不做的方向（10-05）：《爷爷的一年》四季篇章。

## 面向谁、做到什么

- 面向照护者、年轻人与老年人都能玩：字号三档、提示文字三档、画面四档（自动／流畅／标准／精美）、音量四档、人物配音开关、朗读提示（默认关）；不设难度；大按钮、手机布局。（目标玩家：10-05 用户同意**暂定**“有老人的年轻家属”为主、其他三类兼顾；正式定法与关卡设计一起待用户定，见 下一阶段规划 第五节第 1 条。）
- 定位是**认知科普与早识别意识**，不是筛查工具。

## 不可突破的边界

- 不诊断、不打分、不输出风险；游戏内统称“认知量表”，不写具体量表名。
- 「记忆」只列小任务的完成方式、早期常见变化和就医建议；措辞待用户以专业背景把关。
- 玩家失误不导致病情进展；爷爷始终是有主见、能干的人。
- 不用浏览器机械朗读。人物配音用本机 AI 预先生成（Qwen3-TTS，Apache-2.0；声线按文字设计，不模仿真人；爷爷声线由用户选定），都有字幕、可关闭；提醒页和说明页不朗读，旁白“朗读提示”默认关。见 [声音设计](./声音设计.md)。
- 不购买积分、不擅自使用付费服务；`Local/` 私有资料不上传、不公开。
- 发布：推到 main 后由 GitHub Actions 跑 `npm run check`、构建单文件并发布到 GitHub Pages（在线试玩）。

# 关卡引导与连续体验

更新：2026-09-21｜状态：逐项核对指南后的交互规范与候选，尚未试玩。

2026-09-22 整理说明：保留为认知关卡的引导依据，不是当前技术样片的剧情或任务清单。方向见 [项目基线](../项目基线.md)，制作验证见 开发计划。

## 1. 核心修正

**应消除的是多余阅读，不是原题允许的说明和示范。**引导应传达原题本来会告诉参与者的信息，不应让玩家额外猜“这关到底要做什么”。

优先使用对象动作、指向、动画及声音；仍有歧义时使用简短口语。目标是尽量不依赖屏幕说明文字，不是强制静音、无语言或无任务符号。

数字、甲乙等题目材料，不属于应消除的长文本说明。阅读和书写题中的文字更是任务本身，不能删除后仍称覆盖原能力。

依据：用户题表第 1 页 MMSE、第 2 页 MoCA；MoCA v7.1 普通话指南共六页；MMSE_ch.doc 开头表格及第一节操作说明。后者内部冲突仍按任务研究文档记录处理。

## 2. 不再统称为“提示”的五种信息

| 类型 | 作用 | 设计边界 |
|---|---|---|
| 设备教学 | 教会拖动、画线、撤销、录音 | 用无关练习材料；不教正式题答案 |
| 任务说明 | 告诉玩家做什么、何时开始及停止 | 原本口头给出的信息可以继续短语音给出，不强迫看说明 |
| 原有示范／练习 | 帮助理解规则，例如连线的前三点、抽象的示例对 | 只在指南规定范围内示范；不是所有题都有示范许可 |
| 作答中辅助 | 重播示范、局部解释、指出错误等 | 分别记录来源；原指南没有规定的，不冒充原有流程 |
| 答案线索／纠错教学 | 给类别、下一步、完整解答等 | 和初次自主作答分开；可以支持玩家完成，但不能混称独立表现 |

“发光”本身没有好坏。照亮操作入口、播放原有示范和逐步指出正确答案是三件不同的事。

## 3. 连线题的具体引导分镜

### 指南事实

题表已有 1→甲→2 的示例箭头；指南说明两套序列各自有顺序、交替连接，指明起点和终点。游戏需要传达这些内容，不应假定仅看三点就一定理解全部规则。

### 动画候选

1. 整个节点布局出现，起点作一次轻微明暗变化，终点出现固定的终止标记。标记不同时暗示完整路线。
2. 一束短光沿 **1→甲→2** 描出两段线，带出“连接”动作；可以用光笔而非大手指遮挡题面。
3. 动画停在 2，光笔退出。示例两段留作静态参照，其余节点不自动发光，控制权明确交给玩家。
4. 玩家从这里继续。拖动手势若尚未学会，在进入题目前用两个无关点练习，不继续演示 2→乙。
5. 若玩家停住，先区分未懂触控还是未懂规则。可主动重播同一示范；仍不理解时用短语音说明“数字和汉字各按顺序，交替连下去”，不直接指下一点。
6. 多次示范重播和新增练习属于游戏辅助安排，不声称指南规定了可无限重播。

不默认播放两套完整有序序列：这会进一步外置顺序知识。确需提供时作为额外规则教学，单独标记。对不熟悉甲乙顺序的人，也不能将困惑简单算为认知困难。

### 引导是否成功

先观察玩家能否解释／表现出交替规则，而不只看是否拖出了下一条线；记录误触、未理解起点、序列陌生和规则错误。无文字动画是否足够，必须由试玩确认。

## 4. 逐类无说明文字方案

“指南事实”与“游戏候选”分列。没有明文示范的题目，不因为想省文字就自行宣布可以演示答案。

| 任务 | 指南中提供／限制的信息 | 不依赖说明文字的候选 | 不能偷偷提供的内容 |
|---|---|---|---|
| 时间／地点定向 | 口头问日期、地点；MoCA 可追问缺少的时间部分（p6） | 简短语音提问，回答区／麦克风指示轮到玩家 | 直接显示当天日历、定位地点；“日历图标”只辅助话题，不能单独表达全部问题 |
| 词语学习 | 口头说明听完再说、无需按顺序，完整学习两轮，提醒稍后回忆（p3）；MMSE 次数另按其来源 | 聆听阶段的中性声纹 → 停顿 → 轮到玩家的麦克风状态；关键要求短语音说清 | 随词出现对应图片或字幕；用图标顺序要求玩家按原序回答 |
| 延迟回忆 | 先不提示；结束自由回忆后才给类别、必要时多选（p5—6） | 重现不含答案的交互位置、短语音询问；主动帮助后口头给类别，再多选 | 首次就展示原对象、首字、候选图；同一环境本身也可能有上下文线索，要承认这种改变 |
| 连续计算 | 给起始数和减数、连续做至停止；必要时可再次介绍要求（p4） | 口头交代，必要时显示起始算式作为视觉辅助候选；结束用清楚的停止声 | 动画演算首个答案、持续代存每步余额；显示算式是改编，不是指南原有的视觉呈现 |
| 命名 | 指向对象并问名称（p2） | 镜头／轮廓轻微强调当前对象，加麦克风状态；必要时短问“这是什么？” | 播放对象叫声、显示名称或用途暗示；用“你看到了什么？”改变命名要求 |
| 准确复述 | 先说明原样重复，读一句后等待（p4）；MMSE 指南限制正式材料重复 | 声音来源亮起 → 读句 → 停顿 → 玩家录音状态；规则用短语音 | 字幕保留原句；用剧情动画表现句义辅助重构；默认无限重播正式句子 |
| 二维／立体图形复制 | 指向模型及空白位置，要求尽量相同（MoCA p1—2；MMSE 第一节） | 模型区域与空白区域先后轻亮，光笔落到空白处；必要时短语音“照这个画” | 替玩家逐边描完整目标；底图描摹、完整答案吸附。复制另一张简单图的练习是新增教学，不是指南示范 |
| 完整画钟 | 口头要求画钟、全部数字、指定时间（p2）；不提供成品参照 | 空白面板及绘制工具；短语音交代目标。数字时间显示可作为明确标注的额外辅助 | 完整钟图标、排列数字动画、正确指针角度动画；它们会提供待生成的结构 |
| 正序数字 | 听完按原序复述（p3） | 用短语音说明，声音播放完后交棒给玩家；正向箭头仅作已学界面标记 | 正式数字卡片留在屏幕。另举数字示范若采用，属于新增练习 |
| 逆序数字 | 听完倒序复述（p3），本指南未列练习例题 | 先短语音说明；反向箭头可辅助已理解的规则 | 将正式序列动画倒排。独立练习材料可以探索，但明确不是原指南步骤 |
| 警觉性 | 口头规定目标时敲、非目标不敲（p3）；没有明确示范序列 | 口头说明加敲击按钮的动作教学；可另设短训练流演示“目标敲／非目标等待”，但标为新增练习 | 正式目标到来时让按钮闪亮、替玩家识别；只示范敲击而没说明非目标不敲 |
| 类别流畅性 | 说明类别、尽可能多、一分钟，准备后开始（p4） | 类别用短语音说清，非钟表形态的进度条表示时限；开始／停止声音明确 | 先摆动物图片或示范列举一串答案；动画类别图标也可能额外启动特定词汇 |
| 抽象共同关系 | 示例对允许追问、必要时给出上位类别；正式两题不额外提示（p5） | 保留示例互动：先尝试，再按需要演示两个例子归入共同类别，类别用短语音说清 | 一开始替玩家回答示例全部过程；正式题播放共同用途动画或给类别标签，提前揭示关系 |
| 三步命令 | MMSE 第一节明确不重复、不示范正式指令 | 先用其他材料学会单个触控动作；正式段仅短语音一次说完整，再交给玩家操作 | 演示整套正式动作、同步一步步箭头或逐步发光；屏幕操作本身仍不同于真实身体动作 |
| 阅读执行 | 书面指令是输入，执行才算完成 | 告示本身放在场景中，轻微指向让人注意；不额外放长说明 | 把告示读给玩家听、播放其动作答案后仍称阅读理解。该项不能完全无文字 |
| 自主书写 | MMSE 第一节要求自主完整句子，不能给内容提示 | 留空白书写位置和工具，短语音邀请自行写一句话 | 示范句子、拼词模板或内容词库；语音转写属于替代，不等价手写 |

复制、阅读等少数任务的模型／书面刺激本来就需要可见；听觉任务中用可见刺激替代则会改变要求。不能套用一条统一的“越多动画越好”。

## 5. 两个容易被忽略的跨关泄题

1. 如果稍后有自主画钟，前一关的计时 UI 不要画出带完整数字与指针的模拟钟；类别流畅性的计时可用进度条。完整钟形图标也应检查是否提供结构线索。
2. 延迟回忆前不要把目标词变成场景物品、配音、奖励名称或下一关示范材料。已经说出的词若在首次回忆过程中被系统全屏列出，也可能继续提示未说出的词，应区分反馈时机。

教学所用例子、环境装饰和过场内容一起检查，而不只检查提示按钮。

## 6. 关卡怎样衔接：单独设计，不靠提示动画解决

这里的“单独设计”指需要明确研究关间联系，不是把剧情和交互分开生产。依据当前开发计划，游戏核心循环和人物关系须共同成形；单关目标、说明、提示、语音、动画与反馈都要在同一场景分镜中一起设计，不能先做题目合集再补剧情。

单关容易理解只解决进入门槛，不自动产生完整游戏。当前不宣称剧情动机与沉浸感已经成立。

连续体验需要同时设计：

- **目标连续：**玩家知道仍在完成同一件事。开头看见目的和未完成状态，不以任务清单逐条朗读代替动机。
- **空间连续：**主要交互发生在可辨识的空间对象上，镜头靠近操作、完成后退回；不一关一张无关界面。
- **行动连续：**上一操作结束的场景后果，让下一处对象自然进入注意，而非突然跳出“下一题”。可用人物视线、物体运动、声音方向，不必全部靠发光。
- **操作连续：**已经学会的拖动／绘制／录音提示不每关重播；新增的认知规则仍必须清楚交代。
- **信息连续：**学习与回忆跨段关联；不强迫其他所有题都共用答案或机器部件。
- **节奏连续：**避免连续长时间作答、全程紧张倒计时；但任务本身的计时要求如保留，需明确开始停止。

### 一种衔接分镜语法（不是最终剧情）

看见当前目的 → 场景对象引起注意 → 镜头靠近 → 原有说明／示范以合适方式出现 → 控制权交给玩家 → 完成或帮助后继续 → 场景产生后果 → 下一行动自然出现。

例如连线的完成可以使一段可见路线形成，镜头顺着它到达下一处；这是一种过渡手法，不能因此宣布连线与下一题已经有主题关系。还需写清“为什么要去那里、在那里做什么、结果对谁有意义”。若这三点说不清，先不锁定背景，也不交给开发者自由补故事。

## 7. 下一轮交互分镜的必填内容

每关标注：指南原说明；原示范范围；进入动画；必要语音；控制权交接；正式作答期间可见／可听信息；主动重播；额外帮助；失败恢复；完成后的世界变化；下一关入口。

每条教学动画说明它在传达“输入方法、任务规则还是答案线索”。试玩先问玩家以为要做什么，再看完成情况，不能把未懂规则归入能力失败。

验收目标是“不读说明文字也能理解和开始”，而不是“屏幕上绝对没有一个汉字”。默认界面尽量无说明文字，听力需要时提供可选择的文字／视觉辅助，并标记对任务的改变。无障碍优先于形式上的纯无字。

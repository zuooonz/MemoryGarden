# 游戏系统（按 main 现在的代码整理）

更新：2026-10-05｜合并自 游戏系统一览、他的地图方案、成长与反馈系统、难度与平衡（原文在 归档）。数值以代码为准，改规则时同步改这里。
一句话：**你在爷爷的一周里当“身边的人”，早上布置环境、白天看时机帮忙，让他尽量自己把事办成；你帮的方式会影响他今天的心情，也影响他明天的日子。**

## 一、一天怎么过

```
简介（今天的事、天气、新道具、邻居托付、昨天留下的影响）
  → 布置（花精力放道具）
  → 白天（他按时间出门办事；你看、倍速、在关键时刻帮）
  → 晚上（镜头回家，他讲一段往事）
  → 结算（三颗星、每件事、你怎么帮的、心情、明天会怎样、现实中）
```

**路线提示（10-13 用户定，同日第二轮按提议细化）**：画的是**他打算走的路**（按 `correctNext` 定下：他偏好认得的路口），不是导航。目的只有两个：布置时让精力花在他真会经过的路口；出门后让你看出他偏了。
- 布置时：画每趟去程（第一趟橙、第二趟蓝），回程不画，去程和回程上的陌生路口标 `?`。放了路标他改走认得的路时，旧线淡出、新线从起点一段段画出来。走进雾里的箭头淡向路面色。
- 出门后：只画正在走的这一程，**去程、回程都画**；默认淡（透明度 0.5），点他（亮 4 秒）或电话、犹豫面板打开时亮。他走过的箭头一个个收起。
- 拐错一次（drift）：原路线变灰、隔一个画一个，拐错的路口标 `✕`，不给新答案。迷路（lost）：路线整条淡出——他心里的路断了，该你出手。
- 认出路（路标、老地标、熟路口）、照你电话里说的走（画你说的那几步）、邻居领了一段：从他所在的路口重画。只有这时重算路线。
- 打电话指路时路线收起；静观时收起。代码在 `routes.js renderRoutes／updateRoutes`，调试 `__mg.routeState()`。

|---|---|---|

## 四、心情

- 每天从 60 起；当天结束 ≥65 得心情星。
- 来源分类：邻居招呼（nb）、你的电话和陪伴（you）、被人需要（needed）、做喜欢的事（fun，**只按三成**）、自己做到（self）、道具帮上忙（support）、着急迷路（worry）、被替他做（donefor）、没办成（fail）。
- 主要变动：自己办成一趟 +5；一上来就告诉 −4；陪早了 −5；邻居道谢 +6；被安排陪着出门 −6／−3（每天一次）。
- **小关卡只加不扣**：找零全对 +3；残局一子不差另 +3（自己做到）。不拿玩家的认知表现惩罚他。
- 结算页有心情账（60 → 当天结果，哪里加、哪里扣）。

## 六、存档与重玩

- 存主线进度、每天开头的快照、每天的最好成绩。
- 每天保留**最好的一次**（排序：星数 → 办成 → 他自己办的 → 心情）；「记忆」页的小任务也保留最好的状态——通关后重玩没做好，不会把记录改差。
- 重玩某天：小镇回到第一次打那天开始时的样子；重玩不改写之后几天的开头快照。

## 八、系统之间怎么连

```
布置（精力） ──→ 雾变淡 ──→ 少犹豫、少迷路 ──→ 准时、自己办成 ──→ 星、心情
                                  │
                        迷路 → 他打来电话 → 你怎么帮（问／指路／陪／不管）
                                  │                     │
                             着急、心情掉          算不算他自己办的
                                  └──────→ 他的日子（明天）←──────┘
犹豫时刻（家里的事） ──→ 等一等／提示／告诉 ──→ 同上
小关卡 ──→ 事办没办成、记忆页完成表
每天结果 ──→ 往事挑哪段 ──→ 结局
```

## 九、难度与平衡

**工具** `Game/tools/weekbalance.mjs`：六种典型玩家 × 7 天 × 300 周，道具跨天保留，小关卡按真人约 75% 全对随机。`--detail 玩家名` 看每天每件事；`--without call|walk|sign|neighbor|home` 做“缺了谁不行”检查（拿掉一种帮法，三星率应明显下降）；也报成就达成率。

| 玩家 | 三星率（第 1—7 天，10-06 深化核心第一批后；09-27 第二轮见归档） |
|---|---|
| 什么都不做 | 37 19 6 26 24 3 1 |
| 放一两样就不管 | 67 32 18 27 23 3 1 |
| 只接他打来的 | 68 66 34 65 48 42 14 |
| 耐心引导（主动打电话） | 70 70 26 67 59 50 25 |
| 合理地帮 | 75 75 100 74 100 100 100 |
| 事事替他做 | 0 0 0 0 0 0 0 |

目标：合理地帮 85% 以上；只耐心引导 40%—70% 并逐渐下降；什么都不做 25% 以下；事事替他做 0%（“都办成”照样能拿）。

**已知问题**（全是模拟，没有真人试玩）
- （10-06 深化核心第一批后）陪同与指路分开了：慌到走不动只能陪；只用电话指路的玩家第 6、7 天三星率 8%／7%，会陪的 37%／33%。
- 第 3、7 天两件事：一件“正是时候”地帮了算一半，还能拿到“他自己办的”星（一件被替他做仍拿不到）。
- 精力每天仍是 3：模拟里“合理地帮”的路标早几天就铺满了，减精力也没影响（试过 2）；后几天的压力改由病程变化给（耐心引导第 5—7 天 59／50／25）。“合理地帮”后几天仍 100%（模拟玩家知道每个路口的雾，真人做不到这么全）。
- 第 1 天偏宽（新手日，保留）；第 3 天（接孙女）对所有人偏难，是时间问题。
- 心情和“他的日子”都在衡量“过得好不好”：分工是“今天”对“明天”，界面上要讲清楚。

未做的改法（路口时机窗口、电话按他的地图指路等）没有做（项目已收尾，见 Logs/状态.md）。

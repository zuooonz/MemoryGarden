# 声音设计（配音与声音空间）

更新：2026-09-25（爷爷改姓李，大家叫他老李；邻居李师傅改为刘师傅）｜配音用本机 Qwen3-TTS（Apache-2.0）预先生成、打包进页面；模型与工具在 `Local/tts/`（私有）。爷爷声线由用户选定“A 温和”。

## 一、配音为了什么（四种价值，逐句评估）

| 价值 | 说明 | 例子 |
|---|---|---|
| 理解与可及性 | 老年玩家、视力不好或不爱读字的人，靠听就能跟上 | 犹豫时刻他说出来；讲座由医生讲；往事由他讲 |
| 剧情过渡 | 不靠弹窗文字，而靠人物说话把场景接起来 | 迷路 → 邻居喊住他 → 指路；取到快递他高兴地说一句 |
| 玩法本身就是听 | 声音是关卡的核心，不是装饰 | 诈骗电话要“听出破绽”（包括声音不像孙女）；包饺子“只说一遍”；菜摊摊主的类别提示 |
| 情感与趣味 | 人物有性格，小镇是活的 | 邻居各有口头禅；老孙大嗓门；孙女叫“爷爷！” |

**每一句都要能回答：它属于哪种价值？不配会少什么？** 答不出来就不配。

## 三、在哪、怎么听（声音空间）

- 听者就是镜头。世界里的声音都有位置：随距离变小、随方向偏左右；另保留一小部分居中的“近声”，远处也听得清。
- 电话里的话：窄频电话音色，贴耳朵，不做空间化。
- 往事：在往事里的那个地方、那件事发生时当场讲（榕树下、小学门口、电影开场、包完饺子……）；没走到就晚上回家讲，并加引子。讲的时候时间暂停，镜头推近。
- 有人说话时，音乐和环境声自动压低。
- 环境声按时段、天气变化；菜市场附近有人声；静观时环境声略大；镜头越远越空旷。

## 四、节奏与平衡

- 同时只说一句；两句至少隔 8 秒（迷路、电话、往事可以打断）。
- 倍速分档：时间停住时说的（往事、犹豫自语、小关卡里的话）和你主动打的电话永远播；迷路、找到路、特殊路口犹豫 4 倍以下播；开心话、邻居、老孙、孙女、棋友、老电影对白 2 倍以下播；纯音效一直有，倍速时稀疏一些。
- 同一句一天最多两次；普通路口的“？”不配。
- 所有配音都有字幕，设置里可以关掉“爷爷的声音”。静观时尽量少干扰：字幕只听不显示（往事字幕只在关掉配音时显示；提示文字选“多”时照常显示）；路线圆点、脚下橙圈收起；静观时不再浮出那句话（只在界面自动变淡时出现）。
- 说明性文字（界面提示、提醒页、新手引导）默认不朗读；为视力不好的玩家另设“朗读提示”，默认关闭，用温和的旁白女声（第二批）。

## 五点五、同时只有一个人说话（09-25 修正）

- 重要的话（往事、他的犹豫和电话、小关卡里的话）等当前这句说完再说，不打断、不重叠；陪衬的话（邻居招呼、摊主随口应答、棋友、老电影）有人在说就不说；重听往事时打断当前的话。
- 说出声的话不再显示字幕；没出声的（没有录音、被频率规则跳过、关了配音、提示文字选“多”）照常显示。往事字幕保留。
- 相邻两句不说同一件事（09-25 检查）：驿站老板只说“是您的快递”（他不知道寄件人和内容），爷爷接“好，好，回家泡上！”；电影开场爷爷说“开演了，快坐下！”，把“年轻时看过”留给往事；比赛到场说“我来报到！”，把“自己走来的”留给往事。取件码点“写好了”后锁住，不会重播。
- 手机报错：打开声音失败（如“failed to start audio device”）、声音解不开等英文报错不再显示给玩家，只留在控制台；真正的程序错误只显示中文提示。解不开录音的浏览器自动改为显示字幕。
- 翻页、换下一步就停掉上一句（09-25）：小关卡（讲座翻页、诈骗电话里你的回应、取件码、摆棋、包饺子结果、摊主要紧的话）新的一句会停掉上一句没说完的；犹豫时刻做了选择，他没说完的那句就停；朗读提示新的一条换掉上一条。
- 手机切到别的 app：游戏自动暂停、声音挂起；回来后点一下（如“继续”）就重新出声。
- 配音编号按台词内容生成，装入前检查不重复（曾因编号重复导致老孙指路时放出医生讲座的话）。

## 五点六、朗读提示（09-26 梳理）

设置里“朗读提示”（默认关）是给不方便看字的玩家的：旁白把**现在要你做什么、正在发生什么**念出来。所有句子在 `Game/src/narr.js` 一张表里——界面显示的也是这一句（唯一来源）。

| 念 | 不念 |
|---|---|
| 每天开头的简介，接着念邻居托的事 | 人物已经说出口的话（有人物配音：爷爷、邻居、摊主、裁判、孙女……） |
| 操作提示：布置、出发、犹豫时刻怎么帮、电话与陪同、老照片、雾、点邻居家 | 结果与得分（对了几样、找零算对几步） |
| 小关卡开头的做法：菜摊三个阶段、取件码、修闹钟、结账、健步走连线、电话指路、摆残局 | 科普卡、讲座正文（讲座有医生配音）、手册、提醒页、结算、事件记录、按钮文字 |
| 犹豫时刻的情形（标题那句由爷爷自己说，旁白接着念情形；第一次由操作提示代替） | 听和记本身就是玩法的关卡：早饭念菜单、短信取件码、包饺子只说一遍、诈骗电话 |

- 规则：同时只一个人说；旁白排在人物说话之后、不打断人物；新的旁白换掉没念完的上一条旁白。
- 写法：一句尽量短、口语；念的字＝屏幕上的字，「」✓★ 在配音稿里换成“问号、对勾、星星”或去掉（`sayable`）。
- 配音：`node tools/voicelines.mjs` 按提示表与台词表同步本机配音清单，再在 `Local/tts` 生成、安装；`datacheck` 核对每一句都有配音、没有多余的旁白配音、录音念的是现在的文字。

## 五点七、音色一致（09-26）

- `Local/tts/voicecheck.py`：用配音模型自带的说话人编码器，把每个角色每句与参考音比音色相似度，列出最偏的。
- `Local/tts/retake.py`：给指定句子（或 `--outliers 角色`：音高偏离超过 2 个标准差的句子）各生成 6 版，自动挑音色最像、音高最接近这个角色中位数的一版；原录音移到 `out/old/`。
- 重音、语气自动判断不了，挑完仍需人耳确认；配音稿可以为语气改标点，不能改字（`datacheck` 只比字）。
- 多音字：配音清单条目可写 `tts`（发音稿），生成时按它念，`text` 仍是文字本身（如象棋“将军”写成“姜军”）。代表性多音字做成试听页请用户听，比试玩快。

## 六、怎么评估

- 机器能查的：每句响度统一（-18 LUFS）；人声与音乐、环境声的比例；空间方向随镜头正确；字幕与声音对得上；关卡里点击时机与语音同步。
- 要人听的（用户试玩）：往事是否动人；自语会不会太频繁；诈骗电话是否能“听出不对”；老年玩家不看字能否跟上。
- 每批做完后，写一段“这一批配音带来了什么”，不值得的就删。

## 开场配乐（09-27）

`audio.js` 的 `playTheme`（总谱 OPENING）：浏览器实时合成、不用音频文件，约 31 秒，按开场画面节拍写好——熟路（F 大调温暖主旋律，钢琴拨弦＋铺底和弦＋低音）→ 起雾（转小调、铺底收暗、旋律稀疏）→ 刘师傅指路、路标立起（回主调、三声小钟）→ 拉远（主旋律再现、渐弱，最后一声钟配标题大字）。跳过时 0.8 秒淡出。参考《鹈鹕骑单车》的生成式音乐做法（学方法、不照搬）。待用户试听。

# 创作过程与 AI 使用证据（《爷爷的一周》原始记录）

> 这是内部的原始记录（决策日志、平衡数据）；对外提交的整理版见 [提交材料/创作过程与AI使用说明](./提交材料/创作过程与AI使用说明.md)。项目早期原型名叫「守护日常」。

更新：2026-09-25｜用途：支撑评审项「AI 使用与创作证据」。记录真实迭代过程与数据，不美化；待用户补充人工部分。

## 分工

- **用户（人工）**：确定 AD／老化主题与社会价值方向、小红花赛道、浏览器单人游戏；指定技术参考（试玩鹈鹕骑车后认可其水准）；把关医学表达边界；试玩与取舍（待补）。
- **AI（Claude Opus 5.5，Claude Code 桌面版）**：分析为何“量表题串剧情”难以成立；提出「守护日常」机制；编写全部代码与文案初稿；搭建无头平衡测试与时长估算工具；在内置浏览器中试玩、截图检查并迭代。

## 关键设计决策（按时间）

1. **放弃“量表题做关卡”**：量表题要求一次性、隔离单一能力、排除练习效应，这与游戏需要的重复、策略、情绪正好相反。改为从 AD 的真实处境出发，让认知特征成为**规则**。
2. **先布置、再观看的“守护”结构**（借鉴塔防的“布置 → 运行 → 调整”循环）：守护的不是基地，而是长辈独立生活的一天。
3. **“自己办成”取代“自主分”**：第一次试玩发现，玩家什么都不做也能拿“自主”星。于是改成按“他自己办成的比例”计分。
4. **偏好熟悉路线**：第一版爷爷只走最短路，老地标形同虚设。改为经过熟悉路口的代价更低，路标因此能**改变他的路线**，布置变成可推理的谜题。
5. **分级提示（犹豫时刻）**：等一等 → 轻提示 → 直接告诉。参考 MoCA 延迟回忆“自由回忆 → 分类提示 → 多选提示”的分级结构，把量表研究用在**机制**上，而不是照搬题目。
6. **难度曲线**：平衡测试显示支持会逐日累积，后几天过于简单。因此加入修路（迫使他走陌生路）、便签按天消耗、每日心力收紧。
7. **可读性**：路线预览圆点、风险路口「？」、以及「他的地图」薄雾（明确标注为艺术表现，不是他看到的景象）。
8. **节奏**：空档自动快进。估算显示默认 2× 时一轮约 18 分钟，低于赛事要求的 20 分钟，因此默认改回 1×（约 25 分钟）。
9. **用户首次试玩反馈后（09-24）**：修复开始当天镜头、车辆穿过修路路段、时间栏跳动、人物倒退走路；家改为无屋顶剖面小屋，吃药、做饭、接电话改用动画演出；每天菜单不同；支持起作用时弹出图标、结算列出明细；加入成就与结局分档。
10. **量表研究进入玩法（用户提议、双方讨论后确定）**：小关卡由玩家完成、嵌在剧情地点里，只选 3 个：菜市场延迟回忆（参考 MoCA 延迟回忆＋分类线索）、社区讲座交替连线（参考连线测验 B）、诈骗电话注意力敲击（参考 MoCA 听字母敲击）。定位为科普，不计分评估。

11. **用户第二、三次反馈（09-24）**：顺路任务、正门进出、邻居家标识；7 关按研究文档重做（每天一个，嵌入剧情地点），迷路时地图指路；适老化设置（字号、难度；浏览器朗读试过后因太机械被用户否决、已移除）；结尾“关于记忆的提醒”（不打分）；改名《爷爷的一周》（用户选定）。
12. **反诈章节（用户指出诈骗电话被跳过）**：原因是“家人约定”卡直接判定识破。重做为完整来电＋找破绽＋核实＋反诈小卡片，并与第 5 天菜市场“留手机号”形成因果。

13. **剧情与关卡统一（09-24）**：每天标题＝核心任务，关卡为核心任务服务（找零并入第 1 天买菜；第 4 天改为露天电影＋修闹钟；第 7 天新增摆残局）；“你”改为中性写法以适合老年玩家；延迟回忆的真实间隔从约 50 秒增加到约 3—5 分钟。

## 后期迭代（09-24—09-25）

- **配音（用户要求全局统筹）**：用本机显卡离线运行开源 Qwen3-TTS 1.7B，先用文字描述设计每个角色的声线，再克隆出全部台词（约 230 句，爷爷声线由用户试听后选定“温和”一版）；ffmpeg 统一响度。声音有空间位置（听者＝镜头），同时只有一人说话；按倍速分档播放。
- **用户试听后的修正**：配音编号冲突导致老孙指路时放出医生讲座的话——改为按台词内容生成编号并在装入前查重；删除 18 段误把内部名称当台词生成的录音；相邻两句同义重复、翻页后上一句还在播、手机切应用回来无声等逐条修正。
- **剧情逻辑（用户逐条指出）**：孙女在上小学没有手机，诈骗改为冒充女儿；诈骗电话改为一问一答；接孙女改为校门口等人；快递员不应知道寄件人和内容。
- **自动测试**：无头 Chrome（显卡渲染）脚本——排版检查（10 种屏幕 × 折叠组合）、设置组合检查（4 种屏幕 × 字号 3 档 × 提示 3 档＝36 种组合，查文字截断、出框、重叠）、7 天乱点回归（自动解连线和摆棋，检查报错、能否走到结算、哪些台词没有录音）；关卡缺失检查；平衡模拟；人车碰撞检测。每个版本部署前跑一遍。
- **美术**：程序化低多边形；人物头像经用户两次反馈（“像韩式”“像猴子脸”）重新配色、调整比例。
- **界面反复返工的教训（09-25）**：顶部面板对齐前后改了 5 版，用户多次指出“还不如刚才”。原因是只看数字、只测部分状态，且无头浏览器最窄只有 500 像素（手机截图其实是 500 宽）。之后改为按真实手机视口模拟、逐状态截图人工看，再加上两个自动检查工具。

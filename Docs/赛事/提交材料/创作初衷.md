# 《爷爷的一周》创作初衷

**一句话**：爷爷记性变差了，但他仍想自己过日子——我们想让玩家体会，好的帮助是帮他自己办成。

队伍：EXP.2086｜赛道：小红花游戏 · 适老关怀

## 为什么做

创作者的研究背景是老化、阿尔茨海默病（AD）与神经科学。我们想做的不是“模拟病人”或认知测验，而是让玩家通过**自己的判断**体会三件事：

1. **早期认知变化常常先影响新近记忆和陌生路线的方向感**，而几十年前的地方和事往往记得更牢。所以游戏里，爷爷靠老地标认路，遇到新修的路、变了样的老电影院就容易迷失。
2. **环境支持能让人更多地靠自己生活**：醒目路标、分格药盒、大字日历、邻居的一声招呼。
3. **帮助要先少后多**：先等一等，再轻轻提示，最后才直接告诉。这一结构参考了认知评估中“自由回忆 → 线索提示 → 选择提示”的分级思路，但游戏不做测验、不打分诊断。“替他做完”能办成事，却会失去“他自己办成”的那颗星。
4. **帮少了、帮多了都有后果**：他迷路时会打电话给你，问一句、指几个路口、还是过去陪他，要你自己判断；放着不管，他可能放弃回家，家里第二天就不放心、要人陪着出门；事事替他做，他也会越来越依赖你。好的照护是在安全和自主之间找刚刚好的那一点。

## 给谁玩

老年人自己，以及家里有老人的子女、照护者、社区工作者和普通公众。操作尽量简单，照顾老年玩家：字号、提示多少、画面档位都可调，可以打开朗读提示；小关卡里游戏时钟停着，不催促。

## 定位与边界

- 定位是认知科普与“早识别”意识，而不是筛查工具。游戏里的 7 个小任务参考了认知量表（MMSE、MoCA）中的题型——延迟回忆、连续减法、数字顺序、交替连线、画钟、三步指令、持续注意、照样复制——按原题的说明与示范规则改编，由玩家在照护行动中完成。游戏内不出现量表名称，不计分、不评估；讲座与结尾提醒说明早期信号和何时就医。
- 另有完整的反诈章节：冒充亲属骗局的破绽、核实方法、“三不一多”、96110。
- 本作品不是诊断或训练工具，不承诺任何医学效果；游戏规则是对真实处境的简化。
